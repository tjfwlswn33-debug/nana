# nana_character v4 — 한 게시판에 세계와 캐릭터 모으기

**스킨은 `nana_character` 하나만 사용합니다.** 같은 게시판의 글쓰기에서 **타임라인 / 캐릭터**를 선택합니다. 연표 게시판을 별도로 만들거나 ID를 연결할 필요가 없습니다.

## 설치

1. 기존 스킨 폴더와 홈페이지 파일을 먼저 백업합니다.
2. ZIP의 `skin/board/nana_character`를 서버의 같은 위치에 업로드합니다.
3. 게시판 관리자에서 사용할 게시판 **하나**의 스킨을 `nana_character`로 선택합니다.
4. 모바일 스킨을 따로 사용하는 엔진이면 같은 폴더를 `mobile/skin/board/`에도 복사하고 선택합니다.
5. 해당 게시판 목록에서 **타임라인 등록** 또는 **캐릭터 등록**을 누릅니다.

로그인 상태와 게시판의 작성 권한에 따라 등록 버튼이 표시됩니다. 파일 업로드는 1개 이상 허용하고, 공개 개인홈이면 목록·읽기 권한을 비회원에게 허용하세요. 스킨은 기존 엔진의 인증·권한·보안토큰·에디터·캡차·첨부·저장 경로를 사용합니다. 별도 DB 테이블을 만들지 않습니다.

### 기존 v1~v3에서 업데이트

- 기존 캐릭터 글은 자동으로 캐릭터로 표시됩니다. 글 내용을 삭제하지 않습니다.
- 기존 `nana_timeline` 스킨과 별도 연표 게시판은 더 이상 필요하지 않습니다. **기존 게시판을 곧바로 삭제하지 마세요.** 저장된 연표 글이 있다면 엔진의 게시물 이동 기능으로 통합 게시판에 옮긴 뒤 각 글을 수정하여 종류를 `타임라인`으로 선택하세요. 첨부 이동은 엔진의 기능을 사용합니다.
- 기존 `settings.local.php`는 유지해도 됩니다. `timeline_board`·`character_board` 값은 v4에서 사용하지 않습니다.
- v4는 `wr_9`에 글 종류를 저장합니다. 다른 스킨에서 `wr_9`를 사용 중인 게시판은 먼저 백업·검토하세요. 기존의 종류 미지정 값은 캐릭터로 취급하고, 수정 화면의 기존 값 선택을 유지하면 해당 값도 보존합니다.

## 화면과 작성

목록은 **소개글 → 타임라인 이미지 → 캐릭터 목록** 순입니다. 흰색 박스와 짙은 파란 글자로 표시합니다. 타임라인 이미지를 누르면 같은 게시판의 해당 사건 글로 이동하고, 캐릭터 초상을 누르면 같은 게시판의 프로필로 이동합니다.

타임라인과 캐릭터는 같은 게시판 안에서 별도로 조회·집계합니다. 타임라인이 많아도 캐릭터 목록을 밀어내지 않습니다. `전체 타임라인`은 같은 게시판에서 연표만 모아 보는 화면이며, 별도 게시판으로 이동하지 않습니다. 두 종류의 페이지 수와 검색은 각각의 목록에 적용됩니다.

| 입력 | 타임라인 | 캐릭터 |
| --- | --- | --- |
| 기록 종류 (`wr_9`) | 타임라인 | 캐릭터 |
| 제목 | 사건 이름 | 캐릭터 이름 |
| `wr_1` | 연도·시대 | 직업·소속 |
| `wr_2` | 사건 분류 | 한 줄 소개 |
| 첫 이미지 첨부 | 작은 로고·대표 이미지 | 초상 |
| `wr_10` | 배치 순서 (10, 20, 30…) | 기존 값 보존 |
| 본문 | 사건 설명 | 소개 및 프로필 구역 |

타임라인은 배치 순서의 작은 숫자부터 표시합니다. 같은 값이면 최신 등록 순입니다. 캐릭터는 최신 등록 순이며 페이지로 나눕니다. 수정 시 종류도 바꿀 수 있습니다. 비밀글의 제목·이미지·메타데이터는 목록에서 숨기며, 실제 열람은 엔진에서 권한을 확인합니다.

**수정** 버튼은 글쓴이·해당 게시판/그룹 관리자·최고관리자에게 표시됩니다. 비회원 작성 글은 상세 페이지의 엔진 비밀번호 절차를 이용하세요. 실제 수정·삭제 허용 여부는 엔진이 최종 확인합니다. 댓글 UI는 제공하지 않습니다.

### 캐릭터 정보

생일(`wr_3`), 키(`wr_4`), 종족(`wr_5`), 상징·수호신(`wr_6`), 키워드(`wr_7`), 영문명(`wr_8`)을 선택적으로 입력할 수 있습니다. 비워둔 항목은 상세에서 숨깁니다. 긴 본문은 여분 필드가 아니라 기존 본문 필드에 저장합니다.

```text
초상 옆에 표시할 소개를 적습니다.

## 외형
외형을 자유롭게 적습니다.

## 성격
성격과 행동 양식을 적습니다.

## 지나온 이야기
캐릭터의 이야기를 적습니다.
```

HTML 에디터에서는 제목 2·3 서식으로 구역을 나눌 수 있습니다. DOM 확장이 없는 서버에서는 복잡한 HTML 구역을 안전하게 원형 그대로 표시할 수 있습니다.

## 소개글 설정 (선택)

`skin/board/nana_character/settings.local.php`를 만들어 아래처럼 입력합니다. 업데이트 ZIP에는 이 local 파일이 들어 있지 않으므로 보존할 수 있습니다. 모바일 스킨을 별도로 사용하면 그 폴더에도 동일한 설정을 적용하세요.

```php
<?php
if (!defined('_GNUBOARD_')) exit;
return [
    'story_title' => 'Our story',
    'intro' => "소개 첫 문단입니다.\n\n다음 문단입니다.",
    'timeline_count' => 8, // 첫 화면에 보일 연표 개수 (최대 32)
    'story_link' => '', // 전체 세계관 글 주소 (선택)
    'show_sidebar' => true, // 원래 메뉴가 충분하면 false
];
```

## 원래 메뉴·BGM 연결

**일반 스킨 설치에는 루트 파일을 바꿀 필요가 없습니다.** 다만 게시판을 열면 원래 메뉴·BGM이 빠지는 사이트는 [연결 파일 설치 안내](../integration/README.md)를 참고하세요. 제공된 `index.php`의 `frm_main`·`bgm_frame`·커스텀 메뉴와 `main.php`의 `head.php`·`tail.php`·`site_main` 구조를 유지하는 별도 연결 파일을 ZIP의 `integration/`에 담았습니다.

스킨의 Directory는 보조 메뉴입니다. 기존 커스텀 메뉴를 그대로 복제하지 않습니다. 원래 테마 메뉴를 사용하면 `show_sidebar`를 `false`로 바꿔 중복 메뉴를 끌 수 있습니다.

## 검증 범위

PHP 7.4.33에서 한 테이블의 종류별 조회·검색·페이지·정렬·폼·권한 버튼·연결 URL을 검사했습니다. Chromium에서 320/390/768/1280px 화면, 종류 선택, 같은 게시판 주소, 목록 복귀, 실제 연결 파일의 부모 프레임 유지까지 검사했습니다.

실제 아보카도 DB에 대한 글 저장·업로드·캡차·음원 재생 및 제공되지 않은 커스텀 메뉴 CSS 전체의 통합 검증은 해당 서버에서 필요합니다. 테스트에서는 임시 엔진·음악 프레임 대역을 사용했습니다.
