# 원래 메뉴·BGM을 유지하는 연결 파일

이 폴더는 게시판 스킨과 별도의 **선택 설치**입니다. 게시판을 직접 열면 바깥 메뉴·BGM이 사라지는 사이트에 사용합니다. 원래 메뉴·음악 파일은 재사용하며 새 음악 플레이어를 만들지 않습니다.

## 구조

제공된 사이트는 `index.php`에 BGM 재생용 `bgm_frame`, 본문용 `frm_main`, `custommenu/index.php`가 있습니다. `main.php`는 `head.php`·`tail.php`와 관리자 콘텐츠 `site_main`을 불러옵니다. 게시판을 바깥 프레임 없이 열거나 메뉴의 `_top` 링크로 프레임을 벗어나면 바깥 BGM이 빠질 수 있습니다.

## 적용

1. **현재 서버의 `index.php`, `main.php`를 반드시 백업**합니다. 다른 커스텀 코드가 있다면 제공된 파일과 비교해 보존하세요.
2. 이 폴더의 **`index.php`, `nana-shell.lib.php`를 아보카도 루트에 함께 복사**합니다. 스킨 폴더 안에 넣는 파일이 아닙니다.
3. 이 폴더의 **`main.php`도 루트에 복사**합니다. 첨부된 원본의 `head.php`·`tail.php`·`get_site_content('site_main')`를 유지하고, 직접 접근할 때 바깥 프레임을 복구하는 연결 스크립트를 추가한 파일입니다. 초기 독립 페이지용 main.php를 적용했다면 이 파일로 원래 헤더·푸터 연결을 복원할 수 있습니다.
4. `skin/board/nana_character`도 v4로 업로드합니다. 루트 `head.php`, `tail.php`, `head.sub.php`, `tail.sub.php`, `bgm.php`, `template.bgm.php`, `custommenu/`, CSS·JS는 원래 파일을 유지합니다.
5. 관리자에서 원래 **BGM 사용 설정을 활성화**하고 기존 곡과 메뉴 설정을 확인합니다. 음원 파일을 다른 위치로 옮길 필요가 없습니다.

세 파일은 운영 서버에 자동으로 설치되지 않습니다. ZIP을 푼 다음 위 경로에 직접 배치해야 합니다. 문제가 생기면 백업한 루트 파일을 복원할 수 있습니다.

## 동작

- 스킨을 단독으로 설치해도 게시판 기능은 동작합니다. 기존 index.php가 연결 기능을 지원하지 않으면 자동 이동을 강제하지 않습니다.
- 연결 파일을 함께 설치하면 직접 연 게시판·등록·수정 화면을 원래 `frm_main` 안으로 복구합니다. 현재 게시판·글·종류 선택·검색·페이지를 유지합니다.
- 원래 바깥 메뉴의 같은 사이트 게시판·main.php 링크는 본문 iframe으로 이동합니다. 새 탭·외부 링크는 정상 동작을 유지합니다.
- 게시판 안의 목록·상세·등록 이동은 본문 iframe만 바꾸므로 바깥 BGM 재생 프레임은 유지됩니다.
- 모바일에서도 바깥 프레임을 유지합니다. 제공된 기존 index.php의 모바일 즉시 이동은 BGM 프레임을 건너뛰었기 때문에 사용하지 않습니다.
- 입력 중인 글을 잃지 않도록 자동 연결 확인 중 사용자가 폼을 입력하면 이동하지 않습니다.
- 전달된 주소는 같은 사이트의 `bbs/board.php`, `bbs/write.php`와 허용한 파라미터만 받습니다. 임의 외부 주소·PHP 파일을 로드하지 않습니다.

## 확인

사이트의 원래 index.php로 들어가고, 게시판 주소를 직접 열어보는 두 경우를 모두 확인하세요. 타임라인 등록 → 상세 → 목록, 캐릭터 등록 → 상세 → 목록을 이동하면서 원래 메뉴와 플레이어 조작부가 남는지 확인합니다.

브라우저 자동재생 제한은 그대로 적용됩니다. 음악이 자동으로 시작되지 않으면 원래 재생 버튼을 눌러야 할 수 있습니다. 코드 검증에서는 BGM 프레임이 한 번만 생성되고 이동 중 재생 프레임이 다시 로드되지 않는 구조를 확인했으며 실제 음원을 재생해 검사한 것은 아닙니다. 커스텀 메뉴·플레이어 CSS의 개별 숨김 규칙은 원본 파일과 함께 별도로 확인해야 합니다.
