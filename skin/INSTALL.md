# 여백의 기록 v2 — 아보카도 게시판 스킨

PHP 7.4용 캐릭터·세계관 스킨입니다. 별도 메인 페이지 대신 기존 게시판 안에서 동작합니다.

## 설치 / 기존 버전 업데이트

1. **기존 스킨 폴더를 백업**합니다. 직접 수정한 파일이 있다면 먼저 보관하세요.
2. ZIP 안의 `skin/board/nana_character`, `skin/board/nana_timeline`을 서버의 같은 경로에 덮어씁니다.
3. 관리자에서 캐릭터 게시판은 `nana_character`, 연표 게시판은 `nana_timeline`을 선택합니다.
4. 모바일 스킨을 별도로 사용하는 버전이면 `mobile/skin/board/`에도 동일하게 설치·선택합니다.
5. 브라우저에서 새로고침합니다. v2 CSS 주소에는 캐시 구분값이 포함되어 있습니다.

**루트 `index.php`, `main.php`, `head.php`, `tail.php`는 교체하지 않습니다.** 이전 독립 페이지용 `main.php`를 적용했다면 백업본을 복원하세요. 게시판 URL은 `bbs/board.php?bo_table=실제게시판ID`입니다.

## 소개글 + 연표 + 캐릭터를 한 화면에

캐릭터 게시판의 첫 페이지에 소개글, 연표 미리보기, 캐릭터 목록 순으로 표시됩니다. 검색 결과나 2페이지 이후에는 목록에 집중할 수 있도록 소개·연표를 생략합니다.

`nana_character/settings.local.php` 파일을 새로 만들어 다음처럼 저장하세요. **local 파일은 ZIP에 없으므로 이후 업데이트 때 유지할 수 있습니다.** 반드시 UTF-8, `<?php`로 시작하고 앞에 공백을 넣지 마세요.

```php
<?php
if (!defined('_GNUBOARD_')) exit;
return [
    'story_title' => 'Our story',
    'intro' => "여기에 세계관 또는 관계 소개를 적으세요.\n\n빈 줄로 문단을 나눕니다.",
    'timeline_board' => 'timeline', // 실제 연표 게시판 ID
    'character_board' => 'character', // 실제 캐릭터 게시판 ID
    'timeline_count' => 8,
    'story_link' => '', // 전체 세계관 글 주소 (선택)
    'show_sidebar' => true,
];
```

`timeline`, `character`는 예시 ID입니다. 실제 게시판 ID로 바꾸세요. 연표용 `nana_timeline/settings.local.php`에도 두 게시판 ID를 넣으면 양쪽 메뉴에서 서로 이동할 수 있습니다. 모바일 스킨 폴더를 별도로 사용한다면 local 파일도 동일하게 넣으세요.

연표에는 첫 번째 첨부 이미지를 작은 로고처럼 표시하고, 이미지가 없으면 연도를 표시합니다. 공개 목록·읽기 권한이 1이고 본인인증·그룹 접근 제한이 없는 게시판만 미리보기에 사용합니다. 비밀글·답글·댓글은 조회에서 제외합니다. 설정한 연표가 없거나 비공개이면 빈 연표 안내를 표시합니다. 최대 16개를 표시할 수 있습니다.

## 메뉴와 기존 개인홈 디자인

- 스킨 배경은 투명하고, 글자색·글꼴은 기존 개인홈에서 상속합니다. 종이색 박스와 독립 헤더를 제거했습니다.
- 기존 테마의 전역 스타일과 충돌하기 쉬운 `header`·`nav` 태그 및 `wrapper`·`body` 클래스는 추가하지 않습니다.
- 게시판 안에는 왼쪽 Directory 메뉴가 표시됩니다. 기존 DB 메뉴의 1단계 항목을 현재 회원 등급에 맞게 읽고 홈·캐릭터·연표 바로가기를 제공합니다. 모바일에서는 위쪽 가로 메뉴가 됩니다.
- **이 메뉴는 게시판용 보조 메뉴이며, 제공되지 않은 `custommenu/index.php`를 그대로 재현하는 것은 아닙니다.** 기존 커스텀 메뉴의 이미지·애니메이션·하위 메뉴·로그인·BGM 등은 원래 테마에서 관리합니다.
- 원래 메뉴가 이미 보이는 사이트에서는 `show_sidebar`를 `false`로 설정해 보조 메뉴의 중복을 끌 수 있습니다.
- 원래 메뉴 자체가 보이지 않으면 게시판 관리의 상단 포함 파일 설정과 아보카도의 `_head.php` → `head.php` 연결을 확인하세요. 스킨은 원래 헤더 파일을 강제로 중복 포함하지 않습니다. 루트 인트로를 쓰는 사이트는 메뉴 대상을 기존 `frm_main` 또는 자체 설정에 맞춰 유지하세요.

전달받은 head/tail에는 사이트의 실제 CSS와 커스텀 메뉴 파일이 포함되지 않았습니다. 기본 색상을 상속하도록 맞췄으며, 그 파일들의 실제 레이아웃 동작까지 검증한 것은 아닙니다.

## 캐릭터 작성

- 제목: 이름
- 직업·소속 (`wr_1`), 한 줄 소개 (`wr_2`)
- 선택 정보: 생일 (`wr_3`), 키 (`wr_4`), 종족 (`wr_5`), 상징·수호신 (`wr_6`), 키워드 (`wr_7`), 영문명·다른 이름 (`wr_8`)
- 첫 PNG/JPG/GIF/WebP 첨부: 목록과 상세에 사용할 초상. 투명 배경 이미지도 잘리지 않도록 전체를 표시합니다.
- 입력하지 않은 기본 정보는 상세에서 숨깁니다. 기존 `wr_9`, `wr_10` 값은 수정 시 보존합니다.

일반 본문은 다음처럼 적으면 이름·초상·소개·기본 정보 아래에 소제목과 긴 본문이 이어집니다.

```text
이 부분은 초상 옆에 표시되는 소개입니다.
빈 줄로 문단을 나눌 수 있습니다.

## 외형
머리색, 인상, 의상 등 자유롭게 적으세요.

## 성격
성격과 행동 양식 등을 적으세요.

## 지나온 이야기
세계관 속에서 살아온 이야기를 적으세요.
```

HTML 에디터에서는 **제목 2(h2) 또는 제목 3(h3)** 서식으로 구역을 나누세요. 긴 내용은 모두 기존 본문 필드에 저장하므로 255자 여분 필드에 잘려 들어가지 않습니다. 일반 텍스트 본문의 HTML은 이스케이프하고, HTML 글은 엔진이 변환한 본문 서식을 사용합니다. 기본 정보는 255자 이내의 짧은 값으로 입력하세요.

## 연표 작성 / 권한

- 제목: 사건 이름 / `wr_1`: 연도·시대 / `wr_2`: 사건 분류 / 본문: 사건 이야기
- 목록 본문 사용을 활성화해야 목록의 요약이 표시됩니다.
- 정렬은 엔진의 기본 게시판 정렬(기본적으로 최신 글 우선)입니다. 연도 문자열로 자동 정렬하지 않습니다.
- 파일 업로드 수는 1개 이상으로 설정하고 호스팅의 용량 제한을 따르세요.
- 개인 기록용이면 작성 권한을 관리자·본인으로 제한하세요.
- 비밀글은 목록에서 제목·이미지·메타데이터를 숨기며 실제 열람 권한은 엔진이 검사합니다.
- 이 스킨은 댓글 UI를 제공하지 않습니다.

## ‘목록으로’ 오류 대응

v2는 엔진의 `$list_href` 값에 의존하지 않고 **`G5_BBS_URL/board.php?bo_table=게시판ID`**를 직접 생성합니다. 현재 글 번호와 수정 파라미터는 빼고, 검색·분류·페이지 정보만 유지합니다. 하위 폴더 설치와 iframe 안에서의 복귀를 검사했습니다. 기존 엔진이 이미 HTML 인코딩한 링크도 다시 이중 인코딩하지 않도록 처리합니다.

기존 오류 문구·주소를 확보하지 못했으므로 과거 오류의 정확한 원인을 확정한 것은 아닙니다. 계속 오류가 나면 주소창 또는 iframe 내부 이동 주소와 서버 오류 로그를 확인해야 합니다.

## 검증

```sh
docker run --rm -v "$PWD:/app:ro" -w /app php:7.4-cli php tests/skin-test.php
docker run --rm -v "$PWD:/app:ro" -w /app php:7.4-cli php tests/public-data-test.php
```

PHP 7.4.33에서 렌더링·목록 주소·비밀글·공개 연표 권한·메뉴 등급·본문 구역·기존 필드 보존을 확인했습니다. Chromium으로 테스트용 엔진 변수와 헤더를 사용해 목록→상세→목록, iframe 이동, 320/390/768/1280px 레이아웃을 검사했습니다. 테스트용 화면은 실제 사이트 또는 실제 DB의 통합 검증을 대체하지 않습니다. 적용 후 실제 서버에서 글쓰기·수정·삭제·업로드·로그인·캡차를 확인하세요.
