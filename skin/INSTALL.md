# 여백의 기록 — 아보카도 게시판 스킨

페이지 교체 없이 **게시판 관리에서 선택하는 스킨**입니다. PHP 7.4 문법을 사용하며, 제공해 주신 `_GNUBOARD_` / `$g5` 기반 아보카도 에디션 구조에 맞췄습니다.

## 설치

1. `board/nana_character`와 `board/nana_timeline` 두 폴더를 서버의 **`skin/board/`** 안에 업로드합니다.
2. 관리자에서 캐릭터 게시판을 만들고 게시판 스킨을 **nana_character**로 선택합니다.
3. 세계관 연표용 게시판을 만들고 스킨을 **nana_timeline**으로 선택합니다.
4. 모바일 스킨을 별도로 선택하는 버전이라면 같은 폴더들을 `mobile/skin/board/`에도 복사하고 모바일 스킨을 선택합니다. 반응형 CSS는 동일합니다.
5. 기존 홈페이지 메뉴에 각 게시판 주소 `bbs/board.php?bo_table=실제게시판ID`를 등록합니다.

**기존 `index.php`, `main.php`, `head.php`, `tail.php`는 교체하지 않습니다.** 앞서 만든 독립 페이지용 파일과 `config.php`도 이 스킨 설치에는 필요 없습니다. 이전에 `main.php`를 교체했다면 백업본을 복원하고 스킨을 적용하세요.

## 게시판 설정 권장값

- 글쓰기·수정: 관리자 또는 본인만 가능하게 설정
- 목록·읽기: 공개 개인홈이면 비회원 열람 허용
- 파일 업로드 수: 캐릭터는 1개 이상, 파일 크기 제한은 호스팅 정책에 맞게 설정
- 목록에서 본문 사용: **활성화** (타임라인 본문 요약에 필요)
- 목록에서 파일 사용 항목이 있는 버전: 활성화 권장
- 페이지당 글 수: 캐릭터 12개, 타임라인 10개
- 댓글: 이 스킨은 댓글 UI를 제공하지 않음
- 목록 정렬: 엔진의 게시판 정렬 설정 사용. 연표의 연도 필드는 표시용이며 숫자 자동 정렬이 아님

## 작성 방법

| 입력란 | 캐릭터 | 타임라인 |
| --- | --- | --- |
| 제목 | 캐릭터 이름 | 사건 제목 |
| 본문 | 프로필·설정 | 사건 내용 |
| 직업·소속 / 연도 (`wr_1`) | 직업, 소속 | 예: 042 / 제1시대 |
| 한 줄 소개 / 사건 분류 (`wr_2`) | 캐릭터 한 줄 소개 | 예: 세계의 시작 |
| 이미지 첨부 | 첫 PNG/JPG/GIF/WebP 파일을 초상으로 표시 | 상세 본문 하단에 첨부 이미지 표시 |

캐릭터 이미지를 누르면 엔진의 해당 글 상세 주소로 이동합니다. 상세 페이지의 수정·삭제 버튼은 엔진에서 권한을 부여한 경우만 표시합니다. 비밀글은 목록에서 제목·소개·연도·이미지를 숨기고 비공개 기록으로 표시하며, 클릭 후 열람 권한은 엔진이 확인합니다. 로그인·업로드·저장·보안토큰·캡차·삭제는 아보카도 기본 처리 경로를 사용합니다. 별도 DB 테이블은 만들지 않습니다.

## 파일 구성

각 폴더는 독립적이며 `list.skin.php`, `view.skin.php`, `write.skin.php`, `skin.lib.php`, `style.css`로 구성됩니다. 색상과 폭은 `style.css`의 `.nana-skin` 변수에서 바꿀 수 있습니다. `.nana-skin` 안에만 스타일을 적용하여 기존 메뉴·고양이 효과·헤더에 영향을 줄입니다.

게시판 본문은 엔진이 변환한 `$view['content']`를 사용하여 기존 에디터 서식을 유지합니다. 실제 아보카도 전체 배포본과 DB가 아직 제공되지 않았으므로 해당 서버에서 글 등록→이미지 첨부→수정→삭제까지 확인해야 합니다. 커스텀 포크의 추가 필수 입력란은 별도 대응이 필요할 수 있습니다.

## 검증

저장소 루트에서:

```sh
docker compose run --rm home php tests/skin-test.php
```

최소 엔진 변수로 목록·상세·글쓰기 렌더링, 비밀글 정보 숨김, 여분 필드와 첨부 삭제 입력란을 검사합니다. 실제 DB 저장·캡차·파일 업로드의 통합 검증을 대체하지 않습니다.
